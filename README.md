# Healthcare Analytics Dashboard – Power BI Project

## Project Overview
This project is a complete Healthcare Analytics Dashboard developed using Power BI to analyze and visualize healthcare operations and performance.  

The dashboard provides insights into:
- Patients
- Doctors
- Departments
- Appointments
- Medical outcomes

The main goal of this project was to transform raw healthcare data into meaningful business insights that support better decision-making.

# ETL Process

## Extract
- Imported healthcare datasets into Power BI
- Connected and gathered data from multiple tables/files

## Transform
Using Power Query, the data was cleaned and transformed through:
- Removing duplicates
- Handling missing values
- Correcting data types
- Renaming columns
- Creating calculated columns
- Formatting dates and categorical fields
- Data normalization

## Load
- Loaded the cleaned datasets into Power BI Data Model
- Built relationships between tables for efficient analysis

---

# Data Modeling
- Created relationships between datasets
- Designed a structured star-schema model
- Optimized the model for performance and scalability
- Built calculated measures using DAX

---
